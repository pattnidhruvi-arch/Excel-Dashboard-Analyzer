# 📊 Excel Analyzer – Sales Dashboard

## 📌 Project Overview

The Excel Analyzer is a Microsoft Excel-based project designed to analyze sales data and present meaningful insights through formulas, charts, and an interactive dashboard.

This project helps users understand sales performance, calculate percentages, analyze data, and make better decisions.

## 🎯 Objectives

- Analyze sales data using Microsoft Excel.
- Calculate total sales and percentages.
- Understand sales performance.
- Create charts and visual representations.
- Develop an interactive sales dashboard.

## 🛠️ Tools & Technologies

- Microsoft Excel
- Excel Formulas
- Charts & Graphs
- Pivot Tables
- Data Analysis

## 📈 Key Features

- Sales Data Analysis
- Percentage Calculation
- Grade and Performance Analysis
- Data Visualization
- Interactive Dashboard
- Charts and Graphs
